# 规划方法指南（第 2–4 步配套）

> 本文覆盖：定位决策点模板（第 2 步）、目录归纳法（第 3 步）、README 体系说明（第 4 步）。
> 来源：真实知识库整理案例的方法论提炼。

---

## 一、决策点模板（第 2 步 · 定位与内容规划）

与用户拍板前，先按四组决策点做**多档位对比**。每组给出 2–3 个档位、各自优劣、**一个推荐 + 理由**；由用户拍板，不代做决定。

| # | 决策点 | 常见档位 | 备注 |
| --- | --- | --- | --- |
| 1 | **服务场景** | 私有专属 / 公域开放 / 双轨（核心层私有＋精选层公开） | 决定公开范围与内容分层 |
| 2 | **范围边界** | 本地精深＋广域视野 / 单一聚焦 / 泛化 | 含"与相邻库的内容边界"（如各类目知识库之间互斥规则） |
| 3 | **目标人群** | 全周期分层 / 某阶段为主（准备期 / 经营期） | 决定内容深度侧重 |
| 4 | **一句话定位** | 给 3 个不同风格候选（务实画面型 / 锐利态度型 / 平实信息型） | 最终选定后进入介绍文案 |

**方案交付物**（讨论稿 → 定稿）：

1. 背景盘点（已有资产校准）；
2. 决策点对比表（各档位 + 推荐 + 理由）；
3. 一句话定位 + 介绍文案（完整版 / 精简版）；
4. 适合人群（主要面向 / 不太适合）；
5. 内容规划草案（板块级别，不细到目录）；
6. 待拍板清单（编号，便于逐项回复）。

> **原则**：判断类问题先给方案与权衡（对比表、多档位），由用户决定；不确定处逐项询问，不自作主张。

## 二、目录归纳法（第 3 步 · 目录体系）

### 三步法

1. **通读快照**：读完所有条目标题，通读（或抽样读）内容；
2. **按标签 / 主题聚类**：把条目按实际主题聚成簇（若内容自带话题标签，标签是第一线索）；
3. **演绎板块**：把聚类归并成 5–7 个板块（**宁少勿多**），每个板块用一个"回答的问题"定义。

### 六条原则

1. **从内容归纳，不从外部框架演绎**——用既有资料的章节结构（如某本书、某白皮书）当骨架，会把"编写视角"误当"知识库视角"，导致侧重偏差（教训案例：以白皮书八篇为骨架、聚焦"开办/财税"等启动事务，与库内真实内容重心错位，被要求重构）；
2. **板块数宁少勿多**：一级 5–7 个为宜；每个板块回答一个明确的问题；
3. **尽量少设二级**：全库二级目录控制在 0–2 个；只有"特色集中区"才值得设（如本地专题、AI 实践等高频聚集区）；
4. **排序有逻辑**：按"使用者旅程"（认知 → 环境 → 方法 → 案例 → 资源）或"组织逻辑"排序，并在方案中说明；
5. **板块名 = 回答的问题**：命名让人一眼知道"什么问题来这里找"；
6. **存量归位预览**：方案中附"存量 → 目标"的归位预览（让用户验收时能看出每条的去向）。

### 方案交付物

板块表（板块 / 回答的问题 / 内容类型 / 排序 / 二级目录）＋命名规范＋存量归位预览＋与既有资料的关系（哪些旧资料降为素材）。

## 三、README 体系说明（第 4 步 · 骨架与 README）

### 文件布局

```
{库名}/
├── 00-README.md            # 根说明
├── 01-{板块}/00-README.md   # 每个一级板块一份
├── 02-{板块}/00-README.md
└── …（二级目录默认不单独写 README）
```

### 根 README 要素（模板见 templates/readme-root.md）

定位一句话 → 这是什么 → 内容地图（板块表）→ 适合人群 → 如何使用（含检索建议）→ **内容整理说明（供整理者与 AI 工具读取）** → 目录地图 → 更新记录。

### 板块 README 要素（模板见 templates/readme-board.md）

这个板块有什么（含典型内容示例）→ 收录标准（进 / 不进）→ 怎么用 → 与相邻板块的关系。

### 三条实践要点

1. **"内容整理说明"节**同时服务人工与 AI：写清归属判断规则、收录标准、命名建议、库间边界——后续整理/入库时（人或 AI）按它执行；
2. **README 写法兼顾双读者**：给用户看的可读性（示例、场景）＋给机器读的结构化（明确的分类规则字段）；
3. **产出归置**（v1.1 补充）：**交付物**（定位/目录方案、操作地图、机器清单、mapping/config JSON、快照 CSV）与**知识库镜像骨架**同目录平铺，命名统一带「库名」前缀；**一次性脚本与过程副本**放工作空间临时目录（如 `09-临时处理/{任务名}/`），任务完成后可删。两处不得混放。

## 四、验收门清单

| 步骤 | 验收物 | 通过标准 |
| --- | --- | --- |
| 第 1 步 | 存量画像小结 | 用户校准事实无出入 |
| 第 2 步 | 定位与内容规划（定稿） | 用户逐项拍板 |
| 第 3 步 | 内容目录体系方案 | 用户全部验收 |
| 第 4 步 | 骨架 + README 体系 | 用户验收 |
| 第 5 步 | 操作地图 + 机器清单 | 用户确认执行方与批次 |
| 第 6 步 | 核验报告 + 全案总结 | 守恒三项通过 |
